# 🚀 DCEO: 행운의 로또 & 스마트 주식 대시보드

안녕하세요! **DCEO** 저장소에 오신 것을 환영합니다.  
이 프로젝트는 일상의 작은 행운을 찾는 **로또 번호 생성기**와 주식 시장의 흐름을 한눈에 파악할 수 있는 **스마트 주식 현황판**으로 구성되어 있습니다.

초보자분들도 누구나 쉽게 이해하고 바로 사용할 수 있도록 제작되었습니다.

---

## 🍀 1. 행운의 로또 번호 생성기 (`index.html`)

"이번 주 주인공은 나!"  
로또 6/45 번호를 과학적이고 공정하게 추출해 주는 도구입니다.

### ✨ 주요 기능
- **무작위 번호 추출:** 1부터 45까지의 숫자 중 중복 없이 6개를 무작위로 뽑아줍니다.
- **실시간 애니메이션:** 실제 로또 공이 굴러 나오는 듯한 생동감 넘치는 연출을 감상해 보세요.
- **기록 저장 기능:** 이전에 뽑았던 행운의 번호들을 잊어버리지 않게 하단 이력에 자동으로 저장합니다.
- **번호 복사:** 생성된 번호를 클릭 한 번으로 복사하여 가족, 친구와 공유할 수 있습니다.

### 💡 초보자를 위한 Tip
> **알고리즘:** 단순한 무작위가 아니라, 1~45의 숫자를 골고루 섞어 공정한 확률로 번호를 추출합니다. 하단의 **'자주 나온 숫자'** 통계를 참고하여 나만의 전략을 세워보세요!

## 📈 2. 스마트 주식 현황판 (`stock.html`)

"주식 공부, 이제 어렵지 않아요!"  
실제 시장 데이터를 기반으로 주가의 흐름을 시각적으로 보여주는 대시보드입니다.

### ✨ 주요 기능
- **실시간 시세 확인:** 삼성전자, SK하이닉스 등 주요 종목의 실시간 주가 변동을 확인할 수 있습니다.
- **다이내믹 차트:** 주가가 오르고 내리는 추세를 그래프(Chart)로 한눈에 파악해 보세요.
- **관심 종목 관리:** 내가 궁금한 종목을 직접 추가하거나 삭제하여 나만의 포트폴리오를 구성할 수 있습니다.
- **한국형 색상 적용:** 상승은 **빨간색(▲)**, 하락은 **파란색(▼)**으로 표시되어 한국 주식 시장의 느낌을 그대로 살렸습니다.

### ⚠️ 주식 초보자 주의사항 (필독!)
1. **데이터 소스:** 본 대시보드는 **Google Finance**의 최신 데이터를 기반으로 시작하지만, 이후 변동은 학습용 **시뮬레이션**으로 작동합니다.
2. **실제 투자:** 화면에 표시되는 가격은 실제 시장 가격과 실시간으로 100% 일치하지 않을 수 있습니다. **실제 투자 결정 시에는 반드시 증권사 HTS/MTS를 확인하세요!**
3. **학습용 도구:** 그래프의 흐름을 읽는 연습이나 주가 변동에 익숙해지는 연습용으로 활용하시길 권장합니다.

## 🛠️ 사용 방법 (How to Start)

1.  **파일 다운로드:** 이 저장소의 소스코드를 다운로드하거나 `git clone` 명령어로 복제합니다.
2.  **브라우저 실행:** `index.html` 또는 `stock.html` 파일을 더블 클릭하여 크롬(Chrome)이나 엣지(Edge) 브라우저에서 바로 실행합니다.
3.  **별도 설치 불필요:** 복잡한 프로그램 설치 없이 웹 브라우저만 있으면 어디서든 사용할 수 있습니다.
